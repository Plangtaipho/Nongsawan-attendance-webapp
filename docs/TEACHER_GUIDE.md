# คู่มือครู: ระบบบันทึกการสอน (เช็คชื่อและบันทึกหัวข้อที่สอนด้วยมือถือ)

1. เปิดลิงก์ระบบที่โรงเรียนแจ้ง แล้วเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านที่ได้รับ
   - ครั้งแรกให้ไปที่ เมนู → **บัญชีของฉัน** เพื่อเปลี่ยนรหัสผ่าน
   - แนะนำให้กด "เพิ่มไปยังหน้าจอหลัก" ในเบราว์เซอร์ จะเปิดได้เร็วเหมือนแอป
2. หน้า **เช็คชื่อ** เลือก วันที่ (ปกติเป็นวันนี้) → ห้อง → คาบ (ระบบเลือกคาบปัจจุบันให้) → วิชา
3. ทุกคนเริ่มต้นเป็น **มา** ให้แตะเฉพาะคนที่ **สาย / ขาด / ลากิจ / ลาป่วย** และพิมพ์หมายเหตุได้
4. พิมพ์ **หัวข้อที่สอน** และกิจกรรม แล้วกด **บันทึกการเช็คชื่อ** ด้านล่าง
   - ถ้าบันทึกไม่สำเร็จ (เช่น เน็ตหลุด) ข้อมูลที่แตะไว้ยังอยู่ กดบันทึกซ้ำได้
5. ต้องการแก้ไข: เลือกห้อง/คาบ/วันที่เดิม หรือเปิดจากเมนู **ประวัติการเช็คชื่อ** แล้วแก้และบันทึกอีกครั้ง
   - แก้ได้เฉพาะคาบที่ตัวเองบันทึก ถ้าต้องการแก้คาบของคนอื่นให้ติดต่อผู้ดูแลระบบ
6. **สรุปรายวัน** แสดงจำนวน มา/สาย/ขาด/ลา และรายชื่อนักเรียนที่ไม่ได้มาเรียน
7. **รายงานรายเทอม** เลือก ภาคเรียน → ห้อง → วิชา → แสดงรายงาน → **พิมพ์ / บันทึกเป็น PDF**
   (ในหน้าต่างพิมพ์ เลือก "บันทึกเป็น PDF" และแนวกระดาษ "แนวนอน")

หมายเหตุ: ถ้าเปิดระบบแล้วหน้าโหลดช้าประมาณ 1 นาที เป็นเพราะเซิร์ฟเวอร์แผนฟรีกำลังเริ่มทำงาน รอสักครู่ได้เลย
